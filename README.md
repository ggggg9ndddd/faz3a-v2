# صندوق فزعة 🧰 — لا تشتريها استأجرها

موقع حجز أدوات للطلاب، وفيه لوحة تحكم للمشرفين.

| الصفحة | لمين | وش فيها |
|---|---|---|
| `index.html` | الطلاب | الأدوات والمتوفر منها حسب التاريخ، والحجز مع رمز، وزر واتساب، ومتابعة الحجز |
| `admin.html` | المشرفين | الحجوزات (قبول / رفض / تسليم / إرجاع)، والمتأخرين، ورسائل واتساب جاهزة، والمخزون والأسعار، والدخل |

> **وضع تجريبي:** إذا كان `assets/config.js` فاضي، الموقع يشتغل والبيانات تنحفظ في متصفحك بس. تقدر تجرب كل شي قبل الربط.

---

## الإعداد (تقريباً 15 دقيقة)

### 1) Supabase (قاعدة البيانات)
1. ادخل [supabase.com](https://supabase.com) وسوّ مشروع جديد (مجاني).
2. افتح **SQL Editor → New query**، والصق محتوى `supabase/schema.sql` كامل، واضغط **Run**.
3. أضف إيميلات المشرفين بنفس SQL Editor:
   ```sql
   insert into public.admins (email) values ('nasser@example.com'), ('supervisor2@example.com');
   ```
4. **Authentication → Users → Add user → Create new user**: سوّ حساب لكل مشرف (إيميل + كلمة سر) وفعّل **Auto Confirm User**.
5. **Authentication → Sign In / Providers**: طفّ **Allow new users to sign up** عشان ما أحد يسوي حساب بروحه.
6. من **Project Settings → API** انسخ **Project URL** و **anon public key**.

### 2) الإعدادات
افتح `assets/config.js` وعبّ الحقول:
```js
SUPABASE_URL: "https://xxxx.supabase.co",
SUPABASE_ANON_KEY: "eyJhbGciOi...",
WHATSAPP_NUMBER: "968XXXXXXXX",       // رقم المشرف
PICKUP_INFO: "مبنى ... — من 8 الصبح لين 2 الظهر",
```
> مفتاح `anon` عادي ينحط في الموقع. الحماية تشتغل من صلاحيات RLS اللي في ملف SQL: الطلاب ما يقدرون يشوفون حجوزات غيرهم، والتعديل للمشرفين بس.

### 3) النشر على GitHub Pages
1. سوّ repo جديد (مثلاً `faz3a`) وارفع كل الملفات فيه.
2. **Settings → Pages → Source: Deploy from a branch → main / root → Save**.
3. بعد دقيقة يصير الموقع على: `https://USERNAME.github.io/faz3a/`
   ولوحة التحكم على: `https://USERNAME.github.io/faz3a/admin.html`

## كيف يشتغل النظام
1. الطالب يختار الأداة والتاريخ ويحجز، ويطلع له **رمز حجز** (مثلاً `K7QM2P`).
2. الحجز يدخل بحالة **بانتظار الموافقة**، والطالب يقدر يرسله للمشرف على واتساب.
3. المشرف يضغط **قبول**، وبعدها **تم التسليم** لما يعطي الطالب الأداة، وبعدها **تم الإرجاع** لما ترجع.
4. إذا عدّى موعد الإرجاع والأداة ما رجعت، الحجز يطلع **متأخر** بالأحمر، وفيه زر واتساب يرسل للطالب تذكير جاهز.
5. النظام ما يسمح يتحجز أكثر من الكمية الموجودة في نفس الفترة، والتحقق هذا يصير في السيرفر.

## تعديلات شائعة
- **الأسعار والأدوات:** من لوحة التحكم → المخزون → تعديل / + أداة جديدة.
- **أقصى مدة للحجز:** `MAX_DAYS` في `config.js`، وغيّر الرقم 30 في `create_booking` داخل ملف SQL.
- **الألوان:** المتغيرات في أول `assets/style.css` (`--brand` هو اللون البرتقالي).
